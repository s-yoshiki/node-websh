Architecture

One protocol declaration, one terminal component, and a transport seam between them.

The shape of it

Repository layout

├── apps/
│   ├── server/            Hono + node-pty + WebSocket, serves the built frontend
│   └── web/               React app built by Vite
├── packages/

The transport seam

TerminalView in packages/terminal-ui is the entire terminal UI, and it knows nothing about WebSockets. It takes a TerminalTransport: 

interface TerminalTransport {
  readonly state: TransportState;
  connect(): void;
  send(message: ClientMessage): void;
  onMessage(listener: (message: ServerMessage) => void): Unsubscribe;
  onStateChange(listener: (state: TransportState) => void): Unsubscribe;
  dispose(): void;
}

The web app injects WebSocketTransport. Anything else that can carry frames — a local IPC channel, a test double — drops in without the component noticing, which is how majin reuses the same design for a desktop window.

One protocol, imported twice

packages/protocol declares every frame once. Both ends import it, so the two views cannot drift apart.

Why this exists

The previous version declared each half separately and got it wrong: the client sent a resizer field, the server read resize, and window resizing quietly did nothing for as long as that code lived.

The package has two entry points, and the split is deliberate:

Entry point Holds
@node-websh/protocol Types, runtime guards and the transport interface. Isomorphic — nothing here touches a browser global, so the server can typecheck against Node's lib.
@node-websh/protocol/browser WebSocketTransport, which needs WebSocket and location.

Driving a PTY

apps/server/src/pty.ts wraps node-pty. Three details matter:

  • Decoding. node-pty runs its own streaming UTF-8 decoder, so a multi-byte character split across two reads arrives intact and handlers get strings.
  • Locale. When the parent process has no LANG or LC_* — the normal state for a systemd unit or a CI runner — the child gets a UTF-8 locale explicitly. Under LC_CTYPE=C, readline treats typed bytes as 8-bit characters, so entering anything non-ASCII rings the bell and fires filename completion instead of inserting the text.
  • Lifetime. The shell is killed when the socket closes, so a closed tab never leaves an orphan behind.

Build and orchestration

Turborepo runs the task graph. The one ordering constraint that matters is that apps/web builds before apps/server, because the server bundle copies the built frontend next to itself. That is expressed the way turbo understands it: the server lists @node-websh/web as a devDependency.

The server is bundled with esbuild into a single ESM file, with node-pty left external because a native addon cannot be bundled.
